# Hosts_Replicateur

Python package implementing the host-replicator framework.

This package accompanies the papers

- *Multi-strain SIS dynamics with coinfection under host population structure*
- *How host contact network impacts N-strain SIS dynamics with coinfection via a global replicator equation*

by Erida Gjini, Nicola Cinardi and Sten Madec.

## Installation

Download the repository and extract the archive.

## Requirements

- numpy
- scipy
- matplotlib
- networkx (optional)

## Quick start

Run

```bash
python Example_of_use1.py
```

to reproduce two basic examples.

## Files

- `Example_of_use1.py`: minimal working examples.
- `Example_of_use2.py`: minimal working examples using NetworkX.
- `Example_Comparing_Networks.py`: comparison of three host contact networks sharing the same epidemiological parameters.
- `hosts_replicator/`: package source code.
